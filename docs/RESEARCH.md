# Paperclip — Research Document

Paperclip es un plano de coordinación para compañías de agentes: mantiene compañía, roles, tareas, dependencias, revisiones, ejecuciones y actividad. No es el modelo ni el runtime que razona. Un adaptador inicia un proceso o invoca un servicio; en MEDPULSE, process lanza un ejecutor Node que llama a Codex CLI. Los wrappers realizan operaciones administrativas mediante tokens temporales de ejecución; los modelos interpretan los datos y redactan.

La compañía delimita recursos y permisos. Cada agente tiene responsable, rol y configuración. Las tareas conservan documentos, adjuntos y comentarios. Las dependencias encadenan Director → Sales → Strategy → Outreach. Una política de ejecución impide cerrar el borrador hasta la aprobación humana. Si se solicitan cambios, Paperclip registra la decisión y devuelve la tarea al ejecutor. El centro privado conserva la identidad de quien decidió y reserva la consulta del historial a Gerencia. Paperclip admite presupuestos, pero el adaptador `process` usado en la demo no atribuye automáticamente todo el coste del CLI.

Paperclip 2026.1106.0 corre localmente en Windows, con Node 24.22.1 y PostgreSQL embebido. La interfaz y API están en loopback. Company, historial y archivos se guardan localmente bajo .runtime, excluida de Git. Codex usa la sesión ChatGPT existente; no copiamos credenciales al repositorio. Los prompts y los datos entregados al modelo salen al proveedor; la base local completa no se publica. El dashboard Vercel solo consume JSON permitido: ninguna credencial ni acceso al servidor local.

La instalación inicial superó diez minutos. Con Paperclip y Codex listos, el flujo base se reprodujo en 108,82 segundos. El adaptador `codex_local` falló al crear un enlace simbólico de autenticación en Windows y `process` permitió la ejecución. Para actualizar un documento hay que indicar su revisión anterior. Omitirla produjo un conflicto HTTP 409 que se corrigió. MED-22 verificó el traspaso a un simulador HTTP local de WhatsApp y conservó un recibo. Los clientes, compras y consentimientos del flujo comercial son ficticios. Market Intelligence usa avisos oficiales como antecedentes de mercado.
